как получить архив telegram

нужна версия telegram desktop для компьютера.

  1. откройте настройки

    перейдите в «продвинутые настройки» → «экспорт данных из telegram».

  2. выберите переписки

    отметьте нужные чаты. для карты достаточно сообщений — фото и видео можно не включать.

  3. сохраните в json

    в формате экспорта выберите машиночитаемый json. после завершения найдите result.json в папке экспорта.

можно экспортировать и один чат: откройте его меню → «экспорт истории чата» → json.

как читать карту

каждая точка — чат или участник. чем больше сообщений, тем крупнее точка. коралловый цвет выделяет самые активные узлы.

ответы на сообщения
упоминания участников
общие чаты
сообщения рядом по времени
нажмите на точку, чтобы выделить её связи. колесо меняет масштаб, перетаскивание двигает карту. с клавиатуры: tab — вход на карту, стрелки — переход между точками, enter — выбор, esc — снять выбор.
