# telegram constellation: светлый интерфейс

направление: светлый и мягкий интерфейс, выбранный Тимофеем 14 октября. нынешний первый экран перегружен недоступными настройками; маленькие подписи и узкая карта мешают разобраться в данных.

первый экран объясняет результат и предлагает загрузить `result.json` либо открыть вымышленный пример. инструкция экспорта доступна из шапки. до импорта фильтры и пустые счётчики скрыты.

рабочий экран состоит из боковой панели и широкой карты. в панели находятся импорт другого файла, раскрываемые фильтры и список узлов с поиском. выбор строки выделяет точку и показывает её агрегаты. над картой — переключатель чатов и участников, число сообщений, узлов и связей. под картой — легенда, активность по времени и описание выбранного узла. выгрузка текущей карты доступна в svg и png.

палитра: прохладный светлый фон, белые поверхности, синий акцент, тёплый коралловый цвет высокой активности. локальный onest для интерфейса, commit mono для чисел. скругления 14–28 px, ясная иерархия, крупные зоны нажатия, деликатные тени. короткое появление карты и подсветка связей; reduced motion отключает анимацию.

приватность сохраняется: импорт без сети, модель содержит агрегаты, пример создаётся локально, данные не сохраняются между посещениями. удаление данных возвращает первый экран. ошибки нового импорта сохраняют предыдущую карту. пользовательские названия и имена сохраняют свой регистр; название продукта и авторский текст пишутся строчными.

проверка: существующие data/smoke/interaction тесты, новый сценарий примера и поиска, экспорт обоих форматов, клавиатура и мобильные размеры 320/375/768/1440. реальные скриншоты первого экрана, карты и мобильного вида сохраняются в readme. новая версия и readme отправляются в репозиторий после проверки.
