# визуальные правила telegram constellation

интерфейс помогает исследовать карту без предварительного знакомства с настройками. направление обновлено 14 октября 2026: светлый фон, мягкие скругления и ясные действия.

- название продукта везде пишется `telegram constellation`. авторский текст, включая названия сервисов и технологий, пишется строчными. имена людей, пользовательские названия, код, пути и технические идентификаторы сохраняют нужный регистр;
- первый экран предлагает загрузить архив либо открыть вымышленный пример. фильтры и рабочие панели появляются после импорта;
- onest local с кириллицей — основной шрифт. commit mono local — короткие числа, даты и технические имена. все файлы шрифтов хранятся локально;
- базовые цвета: фон `#f3f6fa`, поверхность `#ffffff`, текст `#26344a`, акцент `#376cc5`, точки `#77a0d8`, высокая активность `#e78068`;
- скругления: 20–24 px для панелей, 10–14 px для действий и полей. тени остаются деликатными; точечная сетка поддерживает карту;
- карта занимает основную ширину. список имён и поиск доступны в боковой панели; фильтры раскрываются по отдельному действию;
- выбор узла выделяет его связи и открывает детали прямо над картой. наведение не сдвигает граф. тексты сообщений не выводятся;
- на телефоне фильтры изначально свёрнуты, подписи и области нажатия на точки увеличены. карта поддерживает перемещение и масштаб;
- анимация появления точек короткая; все переходы отключаются при reduced motion. клавиатура, focus-ring и текстовое описание сохраняются;
- ошибка нового импорта сохраняет карту, удаление данных возвращает первый экран. пример не использует сеть или сохранённые пользовательские данные;
- скриншоты readme снимаются с работающего приложения с вымышленными данными: первый экран, выбранный участник, мобильная карта.

перед выпуском запустите data, smoke, interaction, redesign и copy-проверки. описание результата и фактические размеры экрана фиксируйте в `docs/QA-CHECKLIST.md`.
