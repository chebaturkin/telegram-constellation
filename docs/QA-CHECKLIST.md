# чеклист проверки telegram constellation

перед публикацией укажи браузер, viewport, fixture-файл и результат каждой проверки.

## основной сценарий

- [ ] первый экран ясно говорит, что выбранный файл читается локально и не покидает браузер;
- [ ] `result.json` можно выбрать, перетащить или отменить чтение без сломанного состояния;
- [ ] отмена, ошибка или неудачный повторный импорт сохраняют текущую карту и объясняют, что произошло;
- [ ] валидный fixture строит карту без API-ключа, аккаунта, backend и сетевой загрузки;
- [ ] поддерживаются `chats.list`, один объект чата и массив сообщений;
- [ ] обрабатываются `from`, `from_id`, `date`, `reply_to_message_id`, `text`, `entities` и метаданные чата;
- [ ] режим «авто» выбирает слой чатов или участников, а ручной режим меняет его предсказуемо;
- [ ] видны связи ответов, упоминаний, общих чатов и близости по времени;
- [ ] легенда объясняет размер узла, цвет и тип каждой линии;
- [ ] наведение и клавиатурный фокус показывают короткое описание и агрегаты, но не текст сообщения;
- [ ] zoom, pan, фильтры, отдельный сброс фильтров и режим только связей работают вместе;
- [ ] точки шкалы доступны через Tab, Enter и пробел и применяют свои даты;
- [ ] SVG и PNG скачивают именно текущий срез;
- [ ] «удалить данные» очищает модель, фильтры, шкалу, инспектор и имя файла.

## ошибки и приватность

- [ ] прогресс показывает фазу и процент, а после завершения или ошибки исчезает;
- [ ] `fixtures/result-invalid.json` даёт понятную ошибку без stack trace и сырого парсера;
- [ ] пустые экспорты, неизвестный отправитель, service-события и плохие даты не ломают страницу;
- [ ] в Network нет `fetch`, XHR, beacon, WebSocket и сторонних запросов;
- [ ] имена, тексты сообщений и содержимое файла не попадают в URL, history, console, DOM после очистки или экспорт;
- [ ] модель хранит только агрегаты, нужные карте, фильтрам, шкале и экспорту;
- [ ] в localStorage, sessionStorage и cookies не сохраняются пользовательские данные.

## доступность и адаптивность

- [ ] landmarks, заголовки, labels, кнопки, статусы, legend и шкала имеют понятные accessible names;
- [ ] все controls достижимы через Tab, включая SVG-точки и экспорт;
- [ ] focus-ring виден на бумажном и тёмном фоне;
- [ ] Escape снимает выбор, стрелки перемещают фокус по узлам, Enter и пробел выбирают точку;
- [ ] статус, прогресс и ошибки объявляются через live regions без лишнего шума;
- [ ] текстовая альтернатива описывает текущие узлы и связи;
- [ ] цвет не является единственной подсказкой: есть подписи, формы и разные типы линий;
- [ ] при `prefers-reduced-motion: reduce` анимации отключаются;
- [ ] layout проверен на 320, 375, 768 и 1440 px, включая 200% zoom.

## выпуск

- [ ] локальный static server и путь GitHub Pages одинаково загружают относительные assets;
- [ ] после hard refresh данные не восстанавливаются из storage;
- [ ] экспортированные SVG и PNG открываются вне приложения;
- [ ] пройдены `node --test scripts/data-tests.mjs`, `node scripts/design-copy-check.mjs`, smoke и interaction-сценарии;
- [ ] опубликованная страница проверена в браузере после завершения GitHub Actions.


## проверка редизайна 14 октября 2026
