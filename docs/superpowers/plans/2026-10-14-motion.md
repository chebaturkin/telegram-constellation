# план улучшения взаимодействий

цель: событийное движение созвездия и повседневный отклик без изменения текущего дизайна.

архитектура: `app-motion.js` управляет ограниченным набором браузерных анимаций и их отменой. `app.js` сохраняет элементы карты по id и вызывает движение после смысловых действий. `styles.css` содержит общие параметры и тихие состояния контролов.

стек: существующие es-модули, css, svg, web animations api, python playwright. новых зависимостей нет. работа выполняется в текущей папке, чтобы сохранить уже внесённый редизайн.
